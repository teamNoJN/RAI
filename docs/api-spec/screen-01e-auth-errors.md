# 1E번 — 인증 예외 상태

목적: 로그인 실패(401) 인라인 에러 + refresh 실패 시 "세션 만료" 토스트.
버튼 이동: [다시 로그인]→1 (성공 시 2)

## POST /api/auth/login — 401
```json
// Response 401 (공통 에러 계약)
{ "error": { "code": "UNAUTHORIZED", "message": "이메일 또는 비밀번호가 일치하지 않습니다" } }
```

> 노트: 모든 5xx는 공통 에러 문구 + [재시도] 버튼 · 비밀번호 재설정 API 없음(링크 없음)
